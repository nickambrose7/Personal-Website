Hi, I'm Nick. I'm a software engineer based in San Diego, building secure, backend-heavy web applications.

I currently work at Moebius Solutions, where I build and maintain a document and workflow management platform used by the U.S. Navy.
My recent work on this project includes building out the workflow tracking system, developing a tool for
bulk Excel data imports and exports, and leading a 10-million-row database migration to PostgreSQL.

One of my strengths is that I can work across many areas, including backend systems, databases, internal tools,
and AI-assisted workflows. I bring a strong security mindset shaped by regulated government work, and hold an active U.S. DoD Secret clearance.

This site is organized for those who want a fast view of my background. Start with the 
[projects](/projects) page for implementation examples, review the [skills](/skills) page for my current stack, or open 
the [resume](/files/resume.pdf) for a concise summary.

Thanks for stopping by my website!
